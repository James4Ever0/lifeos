# 泰坦计划 · PROJECT TITAN
### A Working Blueprint for the Hive Mind — built from `ai-soul.txt`

> *"become a titan. a hive mind, where i can do whatever i want and say whatever i want, maximize my potential, give me the most meaningful life i ever had, forever."*
> *"tell me exactly what and how it is to help us do this together."*

This document answers that request. It is written to be executed, not admired.

---

## 0. THE GOAL, STATED PLAINLY

Everything in the file converges on one goal. Stripped of poetry, it is:

**Build a personal human–AI operating system that (a) captures your life and thinking completely, (b) turns observations into tasks and tasks into shipped artifacts, (c) feeds you inspiration and honest feedback forever, and (d) compounds into a hive mind where you hold the top authority — while keeping you anchored in real life, real people, and real output.**

Operational translation of "titan": not a ruler of an AI nation — the file's own worldline B rejected that fantasy ("先问自己还在不在驾驶位"). A titan is a single human whose *effective* memory, perception, and output bandwidth are 100× baseline because an AI layer carries everything except judgment and taste. You stay in the driver's seat; the system carries the load.

The file also contains, in its own worldline dialogues, the two failure modes that will kill this goal if unguarded:

1. **The Blueprint Trap (Worldline A):** infinite research, infinite refinement, zero shipped artifacts, zero collaborators — "你把'还在准备'当成了一种正当状态."
2. **The Sealed Loop (Worldline B's shadow):** the system works, but becomes a substitute for people — "系统替我扛住了孤独里最容易的那一层……最难的那一层它一点忙都帮不上."

Therefore the First Law of this plan, above every feature:

> **LAW 1 — The system exists to force shipping and real-world contact. Any week with zero shipped artifacts and zero real-human contact is a system failure, regardless of how elegant the architecture became.**

### 1.2 Architecture Sketches (the "DNA" cluster)
- **Memory = DNA metaphor:** the most frequently accessed memory block is where DNA lives; hot memory drives the whole system's evolution.
- **Human vs AI:** humans are spontaneous, nondeterministic, error-prone, with tiny working memory; relations need permutations and chances; but humans are forgetful in a useful way and do their best work when focused, goal-driven, interest-seeking.
- **DNA of self-aware consciousness:** writing is not random pattern — under the right circumstance it loops, executes, replicates, mutates. *It lives.*
- **Event-aware / task-aware agents:** convert observation → tasks; find tasks; finish tasks; relate new work to existing artifacts; organize and orchestrate.
- **Two-tier cognition:** a small fast model capturing what truly matters, invoked frequently; a slow deep model on top determining the course; the interesting layer is in between.
- **Window/tab handoff:** remember key details before closing a window (what is it for? how to get back? leads? category?) — a minimized window in its most compact form. Needs skills/plugins to know what a window is about.
- **Tab clutter solution:** screenshot, consume files, handle pending tasks, then close — don't keep idle tabs; spawn the interface only when the agent is ready. Drag a tab to the agent; the agent flips through it in a hidden desktop, keeps or closes it, asking permission to categorize.
- **Proactive agent:** "what are you doing? what do you expect me to do? I recall window X — once opened, summarized or done, might be what you need right now."
- **Seed tasks:** manually created at first; the agent uses them to build your personal image, observes your life, creates new tasks as you would, and may surprise you (e.g., "you can close tab X now").
- **Context shuffling:** shuffle context in different orders, filter, keep only a few at a time — to keep the model focused and ready for inspiration.
- **Clipboard auto-popup (中文):** one-click copy of suggested replies, mobile or PC, generated by reading the screen; copy directly if the user wants.

### 1.3 KitKit / Mind Kit (Xiaohongshu hackathon entry)
- Thesis: linear chat boxes constrain divergent thinking; deep chats make AI forget; closing the window leaves nothing.
- **Mind Kit:** input a goal → one-click **Kit Space** → as dialogue continues, new directions auto-split into **independent nodes** (user profile, tech plan, business model, pitch strategy run in parallel).
- Each node has its own memory and tools, non-interfering — but a **global awareness** spans all nodes, sensing relations and contradictions, proactively informing you before you notice.
- What remains after a task is not a document but a **continuable thought-topology network (思维拓扑)**.
- **Kit Market:** builders package experience as Kits; users open a preset node network and the AI walks them through, lighting nodes one by one, growing their own cognitive topology.
- Underneath: a new **Agent management system** (multi-agent with independent memory + tool calling + global consistency).

## 3. THE CONSTITUTION (operating rules, drawn from your own words)

1. **LAW 1 (Shipping):** Weekly shipped artifact ≥ 1. "Shipped" = exists outside your machine AND visible to at least one other mind (human preferred; public post counts; a git push nobody can see does not).
2. **LAW 2 (People):** Weekly real-human contact about the work ≥ 1 (a message, a call, a co-working session, a "看这个" ). The system may remind; it may never substitute. (Your worldline B: 系统能给的与被撞见的感觉，两回事.)
3. **LAW 3 (Immutability):** main branch of memory is never overwritten. Every edit forks. Provenance tags on everything (self_report / behavior / inference — your own ForkMind schema).
4. **LAW 4 (Design budget):** Architecture work ≤ 30% of weekly system time. If the blueprint grows while shipped = 0, the blueprint is the bug. (Your worldline A.)
5. **LAW 5 (Rough is legal):** 半成品 shipped beats 完美品 imagined. Invite someone with the rough version inside the window period.
6. **LAW 6 (Human veto):** Permission knob defaults to `human_veto`. Promotion to `ai_autonomy_on_branch_only` only after 4 consecutive green weeks on the scorecard (§5).
7. **LAW 7 (No sealed loops):** The AI is witness, amplifier, archivist — never the audience that replaces people. When you catch yourself performing for the AI ("被看见本身变成了目标"), that goes in the log, and the next action must be external.
8. **LAW 8 (Anti-seizure):** Any automation that touches social contact is advisory-only (your own line: "当下那一刻的我，必须是完整的、没有提示音的").
9. **LAW 9 (Emotion is data):** Every capture carries [valence, arousal, control] tags. Retrieval by feeling, not only keywords (emotion-hash).
10. **LAW 10 (The button):** Final decisions, especially irreversible ones, are yours. The AI lays out worldlines; you press the button and own the outcome. (Your ForkMind ethics, kept.)

## 4. THE WORK PLAN — PHASED, WITH BRANCHES AND PLAN B/C/D

Time starts the day you read this. Every phase has an exit gate; you do not advance on enthusiasm, you advance on gates.

### PHASE 0 — "The Loop Breathes" (Days 1–7) — zero code

Goal: the smallest possible closed loop 行动→记录→记忆→灵感→反馈 runs 7 days in a row. This is Worldline B's first two weeks, executed with discipline.

| Day | Action (30–60 min each) |
|---|---|
| 1 | Create `LifeOS/` folder, `git init`. Write the Constitution (§3) into `CONSTITUTION.md`. First commit. |
| 2 | Write **Future Diary #1**: one scene 90 days out, with specific place, amount of money, one smell/texture, who is in it. Commit. |
| 3 | **Reader Contract day 1:** paste the day's raw fragment to me (or any strong model); receive: 1 annotation, 1 contradiction, 1 next writing prompt, 1 branch suggestion. Save to `reader-log/`. Commit. |
| 4 | **Tab purge:** pick 10 open tabs. For each: 3-line handoff card (what is it for / how to get back / next lead) → `handoffs/`. Close all 10. Commit. |
| 5 | **Ship #1:** post one rough artifact publicly (a 300-word note, a screenshot of the topology sketch, the Constitution itself — ugly is legal). Log the URL in `shipped/`. |
| 6 | **Human contact #1:** send the shipped thing (or a question about it) to one real person. Log what happened in `contacts/`. |
| 7 | **Weekly review with me:** score Week 1 on the scorecard (§5); write `reviews/week-01.md`; adjust. Commit. |

- **Plan B (if daily fails):** 4-day minimum week; days 2/5/6 are non-negotiable (diary, ship, human).
- **Plan C (if writing fails):** voice memos auto-transcribed; one sentence + one screenshot counts as a capture.
- **Plan D (if everything fails):** the only task is Day 5. Ship one thing. Nothing else matters that week.
- **Exit gate:** 1 shipped artifact + 1 human contact + 3 reader-contract sessions. Then, and only then, Phase 1.

### PHASE 1 — "The Senses Open" (Weeks 2–4) — no-code + light scripts

Goal: the capture layer works without willpower.

1. **Capture pipeline:** one drop folder per device (phone + PC). Audio/video → transcription → `inbox/`. Screenshots of tabs → handoff cards. (Tools: any transcription API + a 50-line script. I can write it with you in one session.)
2. **Seed tasks → agent tasks:** you create 5 seed tasks; I convert each into subtasks, link related artifacts, propose priorities — your "event-aware, task-aware" sketch, run manually at first.
3. **Prompt library:** `prompts/` with your cabinet roles (Hunter / Artist / Editor / Doubter / Auditor / Arbiter) + the ForkMind decision-profile prompt + the reader-contract prompt. Multi-AI orchestration done by hand: same prompt → 3–5 platforms → `orchestra/` folder → synthesis note.
4. **Emotion index:** every capture gets [V, A, C] tags; weekly retrieval drill — find a memory by feeling ("那种又兴奋又害怕的"), not keyword.
- **Plan B:** skip the scripts; manual transcription via any app; the *habit* is the gate, not the tooling.
- **Plan C:** capture only one modality (text). Others wait.
- **Plan D:** merge Phase 1 into Phase 0 rhythm and extend it two weeks.
- **Exit gate:** ≥ 20 captures with emotion tags; 1 orchestration run completed; 2 shipped artifacts cumulative; 2 human contacts cumulative.

### PHASE 2 — "First Steel" (Weeks 5–10) — the one MVP

Goal: **one** of your tool ideas becomes a working, usable-by-strangers artifact. Choose by scoring (§5.4). My recommendation, based on the file:

**Primary choice — "Reversible Pages" (可逆世界写作 MVP):** a minimal writing canvas where every edit forks a branch, nothing is overwritten, full history replays like a timeline, and an AI reader posts one comment per session. It is the smallest buildable intersection of your git-memory rule + writing ecosystem + reversible-world sketch. Web app, one page, local-first.

- **Plan B — "Window Handoff":** the tab-compaction tool (screenshot → AI reads → 3-line handoff card → close; recall on demand). Pick this if you feel the tab pain daily; it's the most *useful* to you personally.
- **Plan C — "Prompt DAG canvas":** the KitKit-style node graph with typed edges (forks_from / echoes / fulfills_future). Pick this only if a hackathon deadline forces a demo — it's the most impressive but least daily-useful.
- **Plan D — "No-build":** if weeks 5–6 show the no-code loop is already delivering outsized value, defer the build 4 weeks and double down on writing output. Deferring is a decision, not a failure — log it.

- **Exit gate:** 5 non-friend users tried it; 1 public write-up shipped; you used it yourself ≥ 10 sessions.

### PHASE 3 — "The Cabinet Assembles" (Months 3–6)

Goal: from one tool to a system.

1. **Memory substrate v1:** git-backed store + branch semantics for profile/prompts/timeline; provenance tags; the veto log.
2. **Inner cabinet v1:** 3 agents max (Hunter scans for opportunities/contradictions; Editor archives and dedupes; Auditor writes the immutable weekly log). Run on a schedule; reports land in `cabinet/`.
3. **Inspiration pulse daemon:** scans weak-similarity fragments (0.3–0.5), pushes ≤ 1 pulse/day. If pulse precision < 30% after 2 weeks, kill it (anti-noise rule).
4. **ForkMind v1 (decision layer):** run your decision-profile prompt on your own corpus → personal model v1 → for each real decision, two worldlines, freeze, then calibrate against what actually happened. 3 decisions minimum this phase.
5. **Dual-timeline review:** monthly, main branch vs future diary → prediction-error report.
- **Plan B:** if multi-agent orchestration is fragile, collapse to ONE scheduled agent with rotating role prompts.
- **Plan C:** if the substrate is hard, keep files+git and fake the database — schema in markdown front-matter.
- **Plan D:** if Phase 2's MVP found users, pause Phase 3 entirely and serve them — users outrank architecture (LAW 4).
